# 📊 Banking Data Science Project  

This project applies **Exploratory Data Analysis (EDA)** and **Data Visualization** techniques to uncover insights from banking datasets. Additionally, a **Power BI Dashboard** is developed to provide an interactive and business-friendly view of customer banking behavior.  

---

## 📌 About  

The project focuses on analyzing banking-related datasets to identify patterns, correlations, and insights across multiple financial variables such as:  

- Customer Income  
- Deposits & Loans  
- Credit Card Balance  
- Checking & Savings Accounts  
- Superannuation Savings  
- Business Lending  
- Foreign Currency Accounts  

It highlights the use of **Python for EDA** and **Power BI for Dashboarding**, combining technical analysis with business-oriented visualization.  

---

## ⚙️ Tech Stack  

- **Python (pandas, numpy, matplotlib, seaborn)** → Data Cleaning, EDA, Visualization  
- **Power BI** → Dashboard for financial insights  
- **Jupyter Notebook** → Data exploration & documentation
